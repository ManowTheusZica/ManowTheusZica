Construo coisa que funciona sem supervisão: robô que roda sozinho, planilha que se
atualiza, PDF que vira dado, API que responde. No Detran-SP isso já significou
**mais de 14 mil registros consolidados** e um fluxo de OCR que substituiu leitura manual.

Aqui no GitHub cada projeto tem número, teste e instrução de rodar — não só print.
